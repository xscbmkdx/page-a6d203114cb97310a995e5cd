品牌简介

LanYu 面向需要跨境访问、高清流媒体和低延迟游戏的用户，提供可订阅的机场线路与 VPN 加速能力。我们把节点质量、客户端兼容和售后响应放在同一套服务里：普通线路满足日常浏览，旗舰与团队套餐开放原生解锁节点和 IPLC 专线。所有订阅与客户端说明以 LanYu 官网为准，避免非官方渠道造成的账号与设备风险。

服务可导入 Clash 系列、Shadowrocket、Surge、Quantumult X 等主流客户端。流量按自然月重置，设备台数按套餐限制。LanYu 持续扩容亚太与北美节点，并对热门流媒体平台做解锁维护，具体可用性随版权策略变化，以实时节点状态为准。

操作说明

  1. 在 LanYu 官网选择基础版、旗舰版或团队版完成订阅，进入用户中心复制机场订阅链接。
  2. 按设备下载对应客户端（见客户端下载一节），仅使用官网列出的应用名称，避免来路不明的安装包。
  3. 在客户端中选择“从 URL 更新订阅”或等效导入方式，粘贴订阅链接并更新节点。
  4. 根据延迟与用途选择节点：日常浏览用普通线路，影视优先解锁节点，游戏优先 IPLC。
  5. 开启系统代理或 TUN/增强模式，确保浏览器与游戏走加速通道。连接异常时切换节点或更新订阅后再试。
  6. 旗舰版与团队版用户可通过优先工单反馈线路与解锁问题，团队版另有客户经理对接窗口。

常见问题

以下问题按使用频率整理，点击即可展开完整说明。更多售后以套餐对应的工单通道为准。

如何确认自己访问的是 LanYu 官网？

请直接通过已收藏的 LanYu 官方网站入口登录。订阅链接、客户端名称和支付说明只在官网用户中心展示。不要向陌生人提供账号验证码，也不要安装群文件中的不明客户端。

机场订阅链接怎么导入客户端？

购买成功后，在用户中心复制通用订阅或分客户端配置。打开 Clash、Shadowrocket 等应用，选择从 URL 添加或扫描配置，更新一次即可看到节点列表。若列表为空，先检查链接是否完整，再尝试更换网络后重新更新。

三个套餐应该怎么选？

轻度浏览和偶尔看视频可选基础版（100GB / 3 台设备）。需要更好的流媒体解锁、游戏 IPLC 和优先工单，选旗舰版。多人同时在线、大流量或需要定制路由，选团队版。年付价格已在各套餐中标明。

流量如何计算，用尽后还能用吗？

套餐流量为当月极速流量，连接产生的实际传输会计入额度。用尽后当月极速通道可能降速或暂停，可升级套餐或等待次月重置。团队版适合持续高用量场景。

是否支持流媒体解锁和游戏加速？

基础版提供基础流媒体解锁与普通线路。旗舰版强调全节点原生解锁，并包含 IPLC 专线游戏加速优化。团队版在此基础上提供 VIP 高带宽节点和定制路由。解锁结果受平台策略影响，以当时节点检测为准。

设备数量超限会怎样？

基础版 3 台、旗舰版 5 台、团队版 20 台同时在线。超出后新设备可能无法建立连接，已连接设备通常不受立即中断。可在客户端中断开闲置会话，或升级到更高台数套餐。

客户端在哪里下载才安全？

以 LanYu 官网下载说明列出的应用名为准，从系统应用商店或官网给出的官方来源安装。不要使用第三方“一键包”或修改版。导入时只粘贴用户中心的订阅链接。
